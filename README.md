# 골드 인테리어

사진과 설명을 직접 수정하고 GitHub에 올리는 정적 홈페이지입니다. 관리자 로그인·사진 업로드 기능은 제거했습니다.

## 수정할 파일
- index.html: 메인 슬라이드, 대표 소개·연혁, 기본 공간 카드의 사진과 문구
- css/style.css: 디자인과 반응형 배치
- js/gallery.js: 기본 공간의 상세 정보와 추가 시공 사진 목록(additionalSpaces)
- js/hero-slider.js: 메인 사진 자동 전환과 조작 버튼
- js/main.js: 모바일 메뉴와 Formspree 상담 문의 전송
- Photo/: 홈페이지 사진. 진선 천장 보정본은 space-wood-clean.png이며 원본 space-wood.jpg도 보존했습니다.

## 로컬 확인
Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```powershell
node server.mjs
```

http://localhost:3000 에서 확인합니다. 서버는 정적 파일 미리보기만 제공하며 로그인·저장·업로드 API가 없습니다. Vercel에서는 HTML/CSS/JS/사진을 정적으로 배포하면 됩니다.

## 사진 변경과 배포
[사진 수정 안내](PHOTO-GUIDE.md)를 참고하세요. 수정·저장 → 로컬 화면 확인 → GitHub 커밋·푸시 → Vercel 배포 상태 확인 순서로 진행합니다. 이 저장소를 올리는 행위와 Vercel의 실제 배포 완료는 별도입니다.

기존 로컬 data/ 폴더는 삭제하지 않았습니다. 현재 홈페이지에서는 읽거나 공개하지 않고 .gitignore로 GitHub 업로드에서도 제외합니다. 이전에 그 폴더에만 등록한 사진은 정적 페이지에 자동 반영되지 않습니다. 공개할 사진을 골라 Photo/에 복사하고 코드 목록에 추가하세요. data 폴더 전체를 업로드하면 안 됩니다.

## 검사
```powershell
node --test
```
정적 페이지·사진 제공, 제거한 관리자/API 경로 차단, 상담 문의의 성공·실패·중복 방지를 검사합니다. 문의 검사는 모의 전송이며 실제 Formspree 메일 수신이나 브라우저 배치를 보장하지 않습니다.

## 상담과 공개 정보
Formspree 문의 주소와 전화·이메일은 기존 설정을 유지했습니다. 실제 메일 수신은 별도 확인해야 합니다. 개인정보 보유·파기 안내는 실제 운영 방식과 맞춰 관리하세요. 대표 소개는 2003년 사업 시작과 에덴 디자인 → 시공간 → 빈체로 → 골드 인테리어 순서를 반영하며, 상호 변경 연도는 확인되지 않아 기재하지 않았습니다.
